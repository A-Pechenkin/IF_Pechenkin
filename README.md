# Тестирование Jira с использованием Selenide и Allure

Этот проект представляет собой набор автоматизированных тестов для веб-интерфейса Jira, написанных на Java с использованием Selenide и Allure для формирования отчетов.

## Описание

Проект автоматизирует основные сценарии тестирования Jira:

* Авторизация пользователя.
* Переход в проект.
* Проверка счетчика задач.
* Проверка информации в задаче.
* Создание бага.

## Запуск тестов

1.  Убедитесь, что переменные окружения настроены корректно.
2.  Запустите тесты с помощью Maven:

    ```bash
    mvn clean test
    ```

## Генерация отчета Allure

1.  После выполнения тестов сгенерируйте отчет Allure:

    ```bash
    mvn allure:report
    ```

2.  Откройте отчет в браузере:

    ```bash
    mvn allure:serve
    ```
