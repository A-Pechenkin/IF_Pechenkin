# Тестирование API с использованием Cucumber и Allure

Этот проект содержит автоматизированные тесты для API, написанные с использованием Cucumber и Rest Assured. Отчеты о выполнении тестов генерируются с помощью Allure.

## Описание

Проект включает в себя тесты для двух API:

1.  **Reqres API:** Тесты проверяют создание пользователя с помощью POST-запроса.
2.  **Rick and Morty API:** Тесты проверяют соответствие информации о Морти и последнем персонаже из последнего эпизода с его участием.

## Структура проекта
* `src/main/java/api.rickandmorty/RickAndMortyApi.java`: Содержит методы для взаимодействия с Rick and Morty API.
* `src/main/java/steps/`: Содержит классы steps для Cucumber.
* `src/test/resources/features/`: Содержит файлы `.feature` с описанием сценариев тестирования.
* `src/test/resources/potato.json`: Файл с данными для создания пользователя.
* `pom.xml`: Файл с зависимостями и настройками Maven.
* `README.md`: Этот файл.

## Запуск тестов

Для запуска тестов необходимо выполнить следующие шаги:

1.  Клонируйте репозиторий.
2.  Перейдите в директорию проекта.
3.  Выполните команду `mvn clean test`.

## Генерация отчета Allure

После выполнения тестов необходимо сгенерировать отчет Allure:

1.  Выполните команду 
    ```bash
    allure serve target/allure-results
    ```
2.  Отчет откроется в вашем браузере.
